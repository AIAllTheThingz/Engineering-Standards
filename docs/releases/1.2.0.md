## Release Scope

The release includes governance-contract improvements, aggregate and pull-request validation, release-lifecycle controls, version-aware downstream compatibility, validator dependency provenance, Python and Bash standards and workflows, maintained examples, isolated home-lab demonstrations, and the controlled Codex behavior evaluation framework.
