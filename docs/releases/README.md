# Release Records

This directory contains immutable published release records and explicitly prepared or unreleased release notes.

| Record | Lifecycle |
| --- | --- |
| [`1.2.0.md`](1.2.0.md) | Published historical release record for annotated tag `v1.2.0`, resolving to immutable commit `6c0050de328ac083e69fbac8971a317689c2c1d6`. |
| [`1.1.0.md`](1.1.0.md) | Published historical release record for tag `v1.1.0`. |
| [`unreleased-consolidation.md`](unreleased-consolidation.md) | Consolidated post-`v1.1.0` development history retained as release-preparation history. |

Published records describe only the immutable tag and commit they name. Prepared or unreleased records must not be interpreted as publication, tag authorization, or a production compatibility promise.

The authoritative current state is maintained in [Release Status](../RELEASE_STATUS.md). Version `1.2.0` is published; later development belongs under [Unreleased](../../CHANGELOG.md#unreleased) and must not be presented as part of the immutable `v1.2.0` release.
