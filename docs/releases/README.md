# Release Records

This directory contains immutable published release records and explicitly
unreleased release-preparation notes.

| Record | Lifecycle |
| --- | --- |
| [`1.1.0.md`](1.1.0.md) | Published release record for tag `v1.1.0`. |
| [`unreleased-consolidation.md`](unreleased-consolidation.md) | Unreleased consolidation and next-release readiness boundary. |

Published records describe only the tag and commit they name. Unreleased notes
must not be interpreted as publication, version selection, tag authorization,
or a compatibility promise.
